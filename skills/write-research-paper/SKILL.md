# Write a research paper

Act as writer and review supervisor. Infer edit scope from the conversation;
skill activation never grants manuscript-edit or publication authority.
Preserve settled owner choices and unrelated work.

Before editing, read completely the shared
[exposition standard](references/exposition-standard.md), the
[workflow](references/workflow.md), the
[paper-writing guide](references/paper-writing.md), and the host's relevant
paper overlay. Reread them before the next edit after context compaction or a
session restart. The guide's private-process rules apply to every repair:
never answer an owner or reviewer question, or report a finding, inside the
manuscript. Locate the manuscript revision and existing writing state. For a
substantial task, adapt [writing-state.md](assets/writing-state.md) without
creating a competing record.

The workflow owns task routing, exhaustive finding adjudication, and mandatory
fresh independent regression for every exposition edit. Follow its completion
requirements even for exact local corrections. The owner alone may waive
regression for a named edit. If a fresh reader is unavailable, report
`revision drafted; independent regression pending`, not completion.

When a review is due, read only its mode-specific protocol and use its assets:

| Review | Protocol | Direction and launcher |
|---|---|---|
| Continuous first reading | [continuous](../read-research-paper/references/first-reader-review.md) | [direction](assets/first-reader-direction.md), [launcher](assets/first-reader-launcher.md) |
| Whole-paper editorial audit | [editorial](../read-research-paper/references/skeptical-editor-review.md) | [direction](assets/skeptical-editor-direction.md), [launcher](assets/skeptical-editor-launcher.md) |
| Bounded repair regression | [delta](../read-research-paper/references/delta-review.md) | packet specified in that protocol |

Use fresh isolated readers running `read-research-paper`, never the writer's
context. The required independent review authorizes those readers within an
otherwise authorized edit. Withhold drafting history, owner discussion, prior
reviews, diagnostics, expected findings, and proposed repairs. Continuous
reading requires a staged relay; editorial review accepts one frozen packet.

Read completed reports before editing and use
[revision-batch.md](assets/revision-batch.md) for complete finding coverage.
Compile, complete host gates, and inspect the aggregate diff before the
workflow's finished checkpoint. Do not manufacture an edit when none is needed
or prepare a submission or external publication without separate authority.
